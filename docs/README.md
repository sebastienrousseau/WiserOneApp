## 🛠️ Documentation Maintenance

This documentation follows the [Diátaxis framework](https://diataxis.fr/):

- **Tutorials** (Getting Started) - Learning-oriented
- **How-to guides** (User Guide) - Problem-oriented
- **Reference** (API docs) - Information-oriented
- **Explanation** (Architecture) - Understanding-oriented

### Contributing to Documentation

Documentation improvements are always welcome! Please:

1. Keep technical accuracy as the top priority
2. Test all code examples before submitting
3. Use clear, concise language
4. Follow the existing structure and style
5. Update this index when adding new documents

### Validation Checklist

All documentation must meet these standards:

- [ ] Code examples are tested and working
- [ ] Links are verified and not broken
- [ ] Terminology matches project glossary
- [ ] Professional but accessible tone
- [ ] No assumptions about reader's environment
- [ ] Clear prerequisites stated upfront
